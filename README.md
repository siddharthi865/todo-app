# Todo App

A modern Todo List built with React + TypeScript + Zustand.

## Features

- Add / Delete / Complete tasks
- Fast state management (Zustand)
- Clean UI (Tailwind + shadcn)

## Tech Stack

- Vite + React 19
- TypeScript (strict)
- Zustand
- React Hook Form + Zod
- Tailwind CSS v4

## Run

npm install
npm run dev
